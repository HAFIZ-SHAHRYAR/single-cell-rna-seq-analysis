# Single-Cell RNA-seq Analysis

## Project Overview

This project focuses on learning and performing
single-cell RNA sequencing (scRNA-seq) analysis
using real biological datasets.

The analysis will use Python (Scanpy) and R (Seurat).

## Research Objective

To identify different cell populations and
investigate gene expression patterns using
single-cell RNA sequencing data.

## Tools and Technologies

- Python
- Scanpy
- R
- Seurat
- Google Colab
- GitHub

## Analysis Workflow

1. Data acquisition
2. Quality control
3. Data normalization
4. Highly variable gene identification
5. Dimensionality reduction
6. Cell clustering
7. Cell type annotation
8. Differential gene expression
9. Biological interpretation

## Project Status

Currently setting up the analysis environment
and preparing the first PBMC dataset.
