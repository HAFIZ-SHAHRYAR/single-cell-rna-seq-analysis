# Analysis Results

This directory contains the output files generated during the single-cell RNA-seq analysis of the PBMC 3k dataset.

## Results files

- `PBMC_cell_type_counts.csv` — Cell counts and percentages for the annotated cell populations.
- `NK_candidates_vs_Cytotoxic_T_candidates.csv` — Differential gene expression results comparing NK-cell candidates with cytotoxic T-cell candidates.

## Figures

Visualizations generated during quality control, dimensionality reduction, clustering, and cell-type annotation will be stored in the `figures/` directory.
